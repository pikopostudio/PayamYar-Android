# پیام‌یار — نسخه بتای برنامه اندروید

این بسته سورس Android Studio برای برنامه مستقل مدیریت زمان‌بندی پیام خصوصی از حساب شخصی تلگرام است. هر گوشی، حساب جداگانه خود را متصل می‌کند. برنامه فقط از **TDLib** و قابلیت زمان‌بندی سمت سرور تلگرام استفاده می‌کند؛ به ربات وابسته نیست.

## قابلیت‌های پیاده‌سازی‌شده در سورس

- UI فارسی راست‌چین برگرفته از طرح تأییدشده؛ داشبورد، مخاطبان، متن‌ها و زمان‌بندی
- اتصال واقعی حساب شخصی با API ID / API Hash و شماره، کد ورود، رمز دومرحله‌ای و ایمیل در صورت نیاز
- دریافت فهرست مخاطبان از Telegram TDLib؛ جستجو، انتخاب دستی و انتخاب موارد نمایشی
- ساخت چند متن با متغیر `{نام}` و تعیین متن اختصاصی هر مخاطب در پیش‌نمایش
- زمان شروع و نرخ ۱ تا ۲۰ پیام در ساعت؛ سقف ۵۰۰ مخاطب در هر کمپین
- بازبینی نام‌ها، متن‌ها و ساعت‌ها؛ تأیید صریح قبل از ثبت واقعی
- ثبت پیام‌ها با **MessageSchedulingStateSendAtDate** در سرور تلگرام؛ بعد از ثبت موفق، اجرای زمان‌بندی مستقل از روشن‌بودن گوشی است
- توقف در خطای API، جلوگیری از تکرار شناسه در همان کمپین، دفتر ثبت محلی و تلاش برای لغو زمان‌بندی‌های تأییدشده
- رمزنگاری API ID و API Hash به کمک Android Keystore، عدم انتقال اطلاعات به سرور شخص ثالث، `allowBackup=false`

## محدودیت‌های مهم نسخه بتا

**این پروژه در محیط فعلی کامپایل یا روی گوشی واقعی و تلگرام زنده تست نشده است**؛ در این محیط Android SDK و دسترسی به مخازن Gradle وجود ندارد، بنابراین **فایل APK آماده و تأییدشده ارائه نشده است**. نیاز است با Android Studio سورس را Sync، کامپایل و ابتدا با Saved Messages/مخاطبان هماهنگ‌شده آزمایش کنید. تغییرات احتمالی TDLib ممکن است نیازمند اصلاح امضاهای متدها باشند.

هنگام ثبت ده‌ها یا صدها درخواست زمان‌بندی، برنامه را تا پایان ثبت درخواست‌ها باز نگه دارید. پس از بسته‌شدن ناگهانی، پیام با وضعیت «در حال ثبت» به حالت «نیازمند بررسی» تبدیل می‌شود و **خودکار دوباره ارسال نمی‌شود** تا خطر پیام تکراری کاهش یابد. ثبت موفق در TDLib لزوماً به معنی تحویل قطعی به مخاطب نیست.

گزینه «لغو» برای پیام‌های تأییدشده درخواست حذف به تلگرام می‌فرستد؛ تا نتیجه برگشتی از سرور را ندیده‌اید، آن‌ها را لغوشده تلقی نکنید. اگر یک کمپین فعال است، برای ساخت کمپین جدید ابتدا صف قبلی را بررسی و لغو کنید.

این ابزار برای ارتباط موردانتظار مخاطبان است، نه پیام انبوه ناخواسته. تغییر تصادفی زمان/محتوا برای دورزدن تشخیص ضداسپم پیاده‌سازی نشده است. تلگرام هیچ نرخ مطمئنی برای جلوگیری از محدودیت یک حساب شخصی اعلام نکرده است.

## پیش‌نیازها

1. Android Studio با Android SDK 35 و JDK 17
2. Gradle 8.9 (محتوای `gradle/wrapper/gradle-wrapper.properties` مسیر نسخه را مشخص می‌کند؛ برای استفاده از Gradle Wrapper استاندارد اگر در سیستم خود Gradle نصب است دستور `gradle wrapper --gradle-version 8.9` را یک‌بار اجرا کنید.)
3. اینترنت برای اولین Gradle Sync و دریافت `io.github.tdlib-android:core:0.1.1` از Maven Central
4. API ID و API Hash مستقل از سایت رسمی https://my.telegram.org

## ساخت APK روی ویندوز

1. ZIP را از حالت فشرده خارج کنید.
2. در Android Studio > Open پوشه `PayamYar_Android_Project` را انتخاب کنید.
3. صبر کنید Gradle Sync تمام شود. اگر Gradle Wrapper خواسته شد، Gradle 8.9 را نصب کنید و دستور بالا را بزنید.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. خروجی مورد انتظار: `app/build/outputs/apk/debug/app-debug.apk`.
6. نصب روی گوشی، ورود با اطلاعات خود شخص و **آزمایش روی تعداد بسیار کم** مخاطبان موافق.

## فونت و طراحی

رابط کاربری اولویت خانواده `Yekan Bakh` برای تیتر و `Vazirmatn` برای بدنه را دارد. فایل فونت تجاری همراه پروژه توزیع نشده است؛ در دستگاه‌هایی که فونت نصب نیست، از فونت عربی/فارسی سیستم استفاده می‌شود. برای خروجی قطعی با فونت یکان‌بخ، نسخه دارای مجوز را بعداً داخل پروژه اضافه کنید.

## نکات حریم خصوصی

- هیچ اطلاعات ورود، API Hash، کد تأیید یا فایل نشست را برای شخص دیگری نفرستید.
- نشست TDLib داخل فضای خصوصی برنامه ذخیره می‌شود. ابزار امکان حساب مستقل برای نصب‌های مختلف دارد؛ حساب‌ها با یکدیگر همگام نمی‌شوند.
- لیست مخاطبان و متن‌ها در حافظه محلی اپ ذخیره می‌شود؛ بکاپ سیستم غیرفعال است.
- درصورت عوض‌شدن حساب، انتخاب مخاطبان قبلی پاک می‌شود؛ برای پاک‌کردن کامل سایر داده‌ها می‌توانید «Clear storage» در تنظیمات اندروید را اجرا کنید.

## ساختار پروژه

- `app/src/main/assets/index.html` — UI و CSS
- `app/src/main/assets/app.js` — کنترل رابط و پیش‌نمایش
- `app/src/main/java/ir/pikopo/payamyar/MainActivity.kt` — پل امن WebView و TDLib
- `TelegramEngine.kt` — احراز هویت، مخاطبان، زمان‌بندی، لغو و خطاهای تلگرام
- `CampaignStore.kt` — گزارش و صف قابل‌ممیزی
- `SecureConfig.kt` — نگهداری رمزنگاری‌شده اطلاعات API

## روش جایگزین: ساخت APK با GitHub Actions (بدون نصب Android Studio)

فایل `.github/workflows/build-android.yml` داخل پروژه قرار دارد و می‌تواند روی GitHub (در صورت موفقیت کامپایل) یک APK آزمایشی بسازد. این مسیر نیاز به حساب GitHub و آپلود پروژه دارد و **هنوز اجرا نشده است**:

1. یک مخزن GitHub خصوصی جدید با نام `payamyar-android` ایجاد کنید.
2. **محتویات داخل پوشه پروژه** را با حفظ مسیرها در ریشه مخزن بارگذاری کنید (نه صرفاً فایل ZIP).
3. در تب **Actions** گردش کار `Build PayamYar Android APK` را از طریق Run workflow اجرا کنید.
4. پس از موفقیت، در اجرای همان گردش کار، قسمت Artifacts فایل `PayamYar-debug-APK` را دانلود کنید.
5. APK آزمایشی را فقط روی دستگاه خودتان برای آزمایش نصب کنید. برای انتشار عمومی، نسخه Release با کلید امضای اختصاصی لازم است.

برای جلوگیری از مشکل امنیتی، هیچ‌وقت اطلاعات شخصی API ID/Hash یا کد ورود را داخل فایل‌های پروژه یا GitHub قرار ندهید؛ برنامه آن‌ها را هنگام اجرا دریافت می‌کند.
